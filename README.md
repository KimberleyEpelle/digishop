# 🛒 Digishop App

**Description:**  
Digishop is a Java-based desktop application designed to help small businesses manage employee data, product inventory, and sales reports efficiently.  
It tracks top-selling products, the employees responsible for each sale, and generates summarized reports for management.

---

## ⚙️ Features
- Manage employee profiles and sales records  
- Track product stock levels and top-selling items  
- Generate top sales reports  
- Simple, lightweight interface built for small retail environments  

---

## 🧠 Tech Stack
- **Language:** Java  
- **Database:** H2 (embedded)  
- **Frameworks/Tools:** JavaFX, JDBC  


---

## 🔐 Security Considerations
- Enforces user login with basic authentication logic
